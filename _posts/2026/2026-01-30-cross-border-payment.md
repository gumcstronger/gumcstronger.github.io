## 跨境平台

跨境收款平台各有优劣处，有的非常麻烦，但又不需要每次上传订单。有得开通容易，又每次需要下载订单上传很麻烦。

## 对比

|                    | Pingpong | 珊瑚跨境         | 连连                                                         |
| ------------------ | -------- | ---------------- | ------------------------------------------------------------ |
| 店铺审核           |          |                  | 非常麻烦,要联系客服或商务，录制App视频操作                   |
| 收款/提现          |          |                  | 未能成功入账，原因为入账额度不足。客服不知道什么原因，等提示 |
| 是否需上传收入订单 | 绑定授权 | 是，等2天审核    | 绑定授权,似乎不需要上传                                      |
| 手续费             |          | 0.7%(暂时收0.5%) | 1%                                                           |
